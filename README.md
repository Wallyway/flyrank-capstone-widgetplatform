# Embeddable Widget & Lead-Capture Platform

FlyRank internship · backend track · capstone.

A customer defines a widget, gets one line of `<script>`, pastes it on any website — and this backend
safely catches whatever the public internet sends back: validated, rate-limited, spam-filtered,
enriched with location data, stored, and shown in a dashboard.

> **Status: in progress.** This README is filled in as the stages land. The full architecture
> diagram, run instructions, API reference and limitations note arrive with the final stage.
